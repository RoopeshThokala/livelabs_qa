# Charts, Maps, and Advanced Pages

## Introduction

In this workshop, you extend the TAP, ESS, and HAA reporting layer with visual analytics. You will build charts, configure an editable leave calendar, create an organisation tree, and show candidates on a map.

Estimated Workshop Time: 40 minutes

### Objectives

In this workshop, you will:

- Add TAP recruitment charts with filtering and drill-through.
- Add ESS dashboard charts, a leave calendar, and an organisation tree.
- Create a TAP candidate-location map.
