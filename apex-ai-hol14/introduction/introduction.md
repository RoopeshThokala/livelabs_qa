# Navigation and Shared Components

## Introduction

Replace the default navigation in the Talent Acquisition Portal (TAP) and Employee Self Service (ESS) applications with a coherent menu, breadcrumbs, quick links, global search, and reusable application settings.

Estimated Workshop Time: 15 minutes

### Objectives

In this workshop, you will:

- Organize TAP and ESS applications' navigation and breadcrumbs.
- Add home-page quick links and global search.
- Create shared configuration values as application settings.
