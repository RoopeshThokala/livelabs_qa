# Page Controls and Components

## Introduction

TAP and ESS already include report pages, but their forms still use the page items generated by the wizards. In this module, you create shared lists of values (LOVs) and configure page items for hiring and employee self-service workflows.

In TAP, you configure the Form on Offers and create an Interview Feedback form. In ESS, you create a Leave Request form and a leave-history report.

Estimated Workshop Time: 20 minutes

### Objectives

In this workshop, you will learn how to:

- Create reusable LOVs in TAP and ESS.
- Configure page items for offers and interview feedback.
- Build an ESS Leave Request form with a leave-history report.
