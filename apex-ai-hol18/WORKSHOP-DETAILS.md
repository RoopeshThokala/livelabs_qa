# Workshop Details

Estimated Time: 20 minutes

## Short Description

Secure Oracle APEX Talent Acquisition Portal and Employee Self-Service Portal applications with authentication, role-based access, row-level filtering, and audit visibility.

## Long Description

In this 20-minute security module, learners configure and brand a controlled custom authentication flow for TAP and ESS, resolve the signed-in employee into session state, and create reusable authorization schemes for recruiting and HR personas. They apply those policies to pages and menu entries, filter Candidate Pipeline data by requisition ownership, and expose an HR-admin-only audit-log report in ESS.

## Workshop Outline

1. Authenticate TAP and ESS users and set the employee session context.
2. Create TAP and ESS authorization schemes.
3. Protect pages and navigation.
4. Enforce Candidate Pipeline row-level filtering.
5. Create and protect the ESS Audit Log report.

## Prerequisites

- An Oracle APEX workspace with Builder and SQL Workshop access.
- TAP and ESS applications and the base TMS schema, including sample job and department data.
- Lab 1 provisions the TMS role tables and active test employees for recruiter, hiring manager, TA administrator, and HR administrator roles.
- Provisioned audit-log table and triggers for leave-request and payslip changes.
