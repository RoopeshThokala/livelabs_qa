# Overview of Oracle APEX Components

## Introduction

After preparing the Talent Management System schema, explore the Oracle APEX development environment. This workshop introduces the components you use to build the Talent Acquisition Portal (TAP) and Employee Self-Service Portal (ESS) in later modules.

You explore App Builder, SQL Workshop, Team Development, and Gallery. You also install and run the APEXToGo sample application and review its navigation, layouts, forms, and reports as examples for your applications.

Estimated Workshop Time: 20 minutes

### Objectives

In this workshop, you will learn how to:

- Navigate App Builder, SQL Workshop, Team Development, and Gallery.
- Navigate the App Builder home page and review an application's main development areas.
- Browse Gallery sample applications and starter applications.
- Install and explore the APEXToGo sample application.
- Recognize design patterns to reuse when building TAP and ESS.

### Prerequisites

- Complete Module 2, **Using SQL Workshop**.
- Access to an Oracle APEX workspace.
