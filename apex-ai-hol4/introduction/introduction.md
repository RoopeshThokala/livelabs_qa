# Introduction to APEXlang and Spec-Driven Development

## Introduction

You are building a Talent Management System (TMS) for Acme Corp. In Module 5, you will create the Talent Acquisition Portal (TAP) application that you will extend throughout the course.

In this module, you will use APEXlang and Spec-Driven Development (SDD) to scaffold a TAP comparison application from a functional specification and schema metadata. You will export an existing application, prepare the source files, generate an Application Blueprint, and import it into APEX.

> **Important:** Use the generated TAP application as a comparison reference. In Module 5, create the TAP application with the **Create App Wizard** and use that application for the remaining modules.

Estimated Workshop Time: 90 minutes

### Objectives

In this workshop, you will learn how to:

- Export and inspect an application in APEXlang format.
- Gather the artifacts that drive an SDD workflow.
- Generate a blueprint for a TAP comparison app.
- Import, run, and assess the generated app before moving to Module 5.

### Prerequisites

- Have access to a database that supports direct connections from Oracle SQL Developer for VS Code.

- Complete Module 2 to create the TMS schema and Module 3 to install APEXToGo.

> **Free Developer Tier:** Direct database connections from Oracle SQL Developer for VS Code are not supported for Oracle APEX Free Developer Tier workspaces. If you are using this tier, you can skip the hands-on labs in this module and continue with Module 5.
