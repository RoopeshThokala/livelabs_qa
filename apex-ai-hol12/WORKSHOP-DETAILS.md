# Workshop Details

Estimated Time: 20 minutes

## Short Description

Configure Oracle APEX Dynamic Actions that provide immediate, data-driven feedback in the Talent Acquisition Portal recruiting and Employee Self-Service Portal applications.

## Long Description

In this 20-minute core-development module, learners use declarative Dynamic Actions to refresh regions, set page-item values, display an AI Assistant, and confirm an invalid leave request. They add a real-time salary-band indicator to Talent Acquisition Portal, refresh candidate data when a requisition changes, and make Employee Self-Service Portal leave and task experiences react to user input.

## Workshop Outline

1. Configure a Talent Acquisition Portal Offer Form salary-band indicator.
2. Refresh Talent Acquisition Portal candidate regions when the selected requisition changes.
3. Add the Talent Acquisition Portal Home recruiter AI Assistant action.
4. Add Employee Self-Service Portal leave, onboarding, and task-state Dynamic Actions.

## Prerequisites

- Access to the Talent Acquisition Portal and Employee Self-Service Portal applications in an Oracle APEX workspace.
- The TMS schema objects and `ess_util.calculate_leave_balance` function are installed.
- An AI provider is configured in the workspace for the Talent Acquisition Portal recruiter assistant.
- Appropriate Builder privileges to edit the referenced pages.
